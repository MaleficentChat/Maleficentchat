# Maleficent Chat 2.2 – requested feature overhaul

Implemented from the September 22 feature request:
- Active-only @mention autocomplete and blue mention rendering.
- Saved message Open navigation into the correct room/message.
- Pinned Messages room menu with all pinned messages for the current room.
- Expanded settings: themes, username color, chat font, text size, effects, compact mode, reduced motion, contrast, privacy, notifications, sessions.
- Friend-only personalized nicknames with private visibility between the two friends.
- Aurora bot: @Aurora truth/dare triggers in every room with randomized prompts.
- Owner feature granting reduced to implemented feature controls rather than a fake 1000-item catalog.
- Clickable message avatars opening profile actions.
- Gold sharing and reusable personalized image/text gifts.
- YouTube search panel and shared embedded videos in chat; optional YouTube API key plus server-side fallback search.
- Staff account controls for username/email and staff rank assignment, gated by Owner-controlled permissions; staff rank assignment cannot exceed MOD.
- System notices for username and moderation changes.
- Smaller user cards and responsive mobile adjustments.
- Permanent Maleficent owner protection retained.
